# Final Code
The code for the models can be found in the [Models](./Models/) directory, with:
- Model-xV notebooks are used to train the architectures with x views
- Python files are helper files for the models
- Attack-X notebooks used to perform attack X (some Attack notebooks without X are just for testing purposes)
- StatTest-X notebooks used to perform the statistical testing on the corresponding attack
- StatTest-Disentanglement notebooks are used for disentanglement testing
